SUGGESTED API FIELDS PER GIFT
================================================================================
{
  "id": "string",              // e.g. "1", "af1", "pk3", "sp8", "vip5", "r2", "iv1"
  "name": "string",            // display name
  "price": number,             // diamond cost (integer); null for relationship videos
  "category": "string",        // "gift" | "random" | "activity" | "pk" | "special" | "vip" | "relationship"
  "subCategory": "string",     // optional: event name for activity gifts
  "emoji": "string",           // fallback icon when imageUrl is null
  "imageUrl": "string|null",   // CDN URL to gift icon/thumbnail (PNG/WebP/GIF)
  "videoUrl": "string|null",   // CDN URL for animated gift or relationship video (MP4)
  "hot": boolean,              // optional badge
  "isNew": boolean,            // optional badge (special gifts)
  "vipLocked": boolean         // true for VIP tab gifts
}

SEND GIFT API (already in app — partyApi.sendRoomGift)
================================================================================
POST /api/v1/tuktuk/rooms/{roomId}/gift

Request body (current app payload):
{
  "giftId": "string",
  "giftName": "string",
  "quantity": number,
  "diamondValue": number
}

Recommended backend response should include imageUrl / videoUrl so the app can
render gift animations instead of emoji-only placeholders.
